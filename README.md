# Мессенджер в стиле Telegram

Внешний вид и поведение приближены к Telegram: список чатов слева с превью
последнего сообщения, переписка — классическими пузырями (свои сообщения
справа, зелёно-белые, чужие — слева, белые), поиск по чатам, статус
"печатает…" в шапке, галочки прочтения.

## Как запустить в VS Code

1. Установи Node.js: https://nodejs.org (LTS)
2. Открой папку `chat-app-tg` в VS Code
3. В терминале (Ctrl + `):
   ```bash
   npm install
   npm start
   ```
4. Открой в браузере: `http://localhost:3000`

## Проверить с "двумя аккаунтами"

Открой обычную вкладку и приватное окно браузера, зайди под разными именами —
сообщения будут приходить друг другу мгновенно.


## Что реализовано

- Список чатов с аватарами, превью последнего сообщения и временем
- Поиск по чатам (фильтрация в реальном времени)
- Пузыри сообщений: свои — справа (зелёно-белые), чужие — слева (белые)
- Группировка сообщений одного автора подряд (аватар только у последнего)
- Галочки "прочитано" на своих сообщениях
- Индикатор "печатает…" в шапке чата
- Счётчик непрочитанных сообщений на чатах, которые сейчас не открыты
- Создание новых чатов

## Дальше можно добавить

- Голосовые сообщения, стикеры, реакции

- Тёмную тему (переключатель)
