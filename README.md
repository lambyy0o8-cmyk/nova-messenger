# Мессенджер в стиле Telegram

Внешний вид и поведение приближены к Telegram: список чатов слева с превью
последнего сообщения, переписка — классическими пузырями (свои сообщения
справа, зелёно-белые, чужие — слева, белые), поиск по чатам, статус
"печатает…" в шапке, галочки прочтения.

## Как запустить в VS Code

1. Установи Node.js: https://nodejs.org (LTS)
2. Открой папку `chat-app-tg` в VS Code
3. В терминале (Ctrl + `):
   ```bash
   npm install
   npm start
   ```
4. Открой в браузере: `http://localhost:3000`

## Проверить с "двумя аккаунтами"

Открой обычную вкладку и приватное окно браузера, зайди под разными именами —
сообщения будут приходить друг другу мгновенно.

## Что реализовано

- Список чатов с аватарами, превью последнего сообщения и временем
- Поиск по чатам (фильтрация в реальном времени)
- Пузыри сообщений: свои — справа, чужие — слева
- Группировка сообщений одного автора подряд (аватар только у последнего)
- Галочки "прочитано" на своих сообщениях
- Индикатор "печатает…" в шапке чата (можно отключить в настройках)
- Счётчик непрочитанных сообщений на чатах, которые сейчас не открыты
- Создание новых чатов
- Тёмная/светлая/системная тема, акцентный цвет, фон переписки, размер шрифта
- **Один аккаунт на устройство + внутренний Nova ID**
- Смена юзернейма в Настройках → Аккаунт (без создания нового Nova ID)
- **Уникальный юзернейм (@username), как в Telegram** — сервер не даст занять юзернейм, который уже используется другим аккаунтом
- Выход из аккаунта (Настройки → Аккаунт → «Выйти из аккаунта»)

## Как работает привязка "один аккаунт — одно устройство"

Это демо-проект без базы данных и без настоящей SMS-регистрации, поэтому
"телефонные номера" здесь — не настоящие: это просто внутренний
идентификатор аккаунта, **Nova ID** (вида `NOVA-482913`), который сервер
генерирует и выдаёт при первой регистрации.

Как это устроено:

1. При первом заходе браузер генерирует случайный `deviceId` и сохраняет
   его в `localStorage`. Это и есть "устройство" в терминах приложения.
2. Клиент отправляет на сервер `{ name, deviceId }`. Сервер смотрит,
   есть ли уже аккаунт с таким `deviceId`:
   - если аккаунта нет — создаёт новый и выдаёт ему уникальный Nova ID;
   - если аккаунт уже есть — **просто логинит в него**, игнорируя
     повторную попытку регистрации. Так с одного браузера/устройства
     нельзя создать второй аккаунт.
3. При следующих заходах имя подставляется автоматически и вход
   происходит без повторного ввода — как "запомнить меня".
4. Nova ID и текущее имя видны в Настройках → Аккаунт; там же можно
   переименовать свой аккаунт (это не создаёт новый — тот же Nova ID
   остаётся).

**Важно:** это работает только в пределах браузера/устройства через
`localStorage` — если очистить хранилище браузера, открыть режим
инкогнито или зайти с другого устройства, сервер увидит "новый"
`deviceId` и создаст новый аккаунт. Для настоящей защиты от
множественной регистрации (как в Telegram) нужна серверная база
данных и подтверждение через реальный SMS-провайдер — здесь этого
намеренно нет, это учебный/демо-проект.

## Дальше можно добавить

- Настоящую базу данных и полноценную серверную защиту аккаунтов
- Реальную SMS/email-верификацию, если нужен production-уровень
- Личные (приватные) чаты 1-на-1, отдельно от групповых
- Голосовые сообщения, реакции
- Пересылку сообщений, ответы (reply), редактирование/удаление
